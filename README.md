# Numberwise

An adaptive maths practice app for Class 3–8, in a single HTML file.

- 12 topics, from place value (up to ten lakhs) to linear equations
- 5 difficulty levels per topic: two first-try answers in a row moves you up a level, and missing a question twice moves you down one
- A hint and a second try after a wrong answer, then a worked solution
- Stars, a daily goal and mastery for each topic, saved in the browser's localStorage

## Run it

Open `index.html` in any browser. It has no build step and no dependencies apart from Google Fonts.
